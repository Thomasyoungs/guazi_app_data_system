# 字段契约规范

字段契约来源为 `config/fields.yaml`。采集系统只允许读取和输出白名单字段，禁止采集合同外数据。

## 目标车字段

| 字段 | 来源 | 必填 | 规则 |
| --- | --- | --- | --- |
| task_id | 飞书系统 | 是 | 只读主键，禁止人工填改 |
| brand | 飞书任务 | 是 | 用于 S03 品牌定位 |
| series | 飞书任务 | 是 | 用于 S04 车系定位 |
| model_year | 飞书任务 | 是 | 用于 S05 年款选择 |
| trim | 飞书任务 | 是 | 用于 S05 精准配置 |
| color | 飞书任务 | 是 | 用于 S07 颜色筛选 |
| registration_date | 飞书任务 | 是 | 提取上牌年份 |
| mileage_10k_km | 飞书任务 | 是 | 目标车打分 |
| transfer_count | 飞书任务 | 是 | 目标车打分 |
| condition_text | 飞书任务 | 是 | 喷漆、换件、硬淘汰识别 |
| accident_count | 飞书任务 | 否 | 缺失时按 4 分并建议人工审核 |
| max_accident_amount | 飞书任务 | 否 | 缺失时按 3 分并建议人工审核 |

正式流程只从飞书任务读取目标车字段。本地 JSON 只能用于模拟测试和离线回归测试。

上牌日期必须保存原始年月值，例如 `2020.4`、`2020年4月`、`2020-04`。三同车源匹配时可派生年份 `2020`，但不能丢失原始上牌日期。

## 参考车字段

| 字段 | 来源状态 | 规则 |
| --- | --- | --- |
| reference_index | S10 | 系统按价格顺序生成 |
| list_price_10k | S08/S10 | 只采集列表页红色价格 |
| list_year | S08/S10 | 只采集标题下方年份 |
| list_mileage_10k_km | S08/S10 | 只采集标题下方公里数 |
| transfer_count | S11 | 只采集页面中间右侧过户次数 |
| accident_count | S12 | 理赔次数映射为出险次数 |
| max_accident_amount | S12 | 最大金额映射为最大出险金额 |
| repair_counts | S13 | 只采集四个区域历史修复次数 |
| panel_repairs | S14 | 历史修复不为 0 时采集 |
| score | S15 | 系统自动计算 |
| is_final_reference | S15 | 系统自动判断 |

## 禁止采集字段

城市、标签、推荐标签、首付、月供、卖家信息、电话信息、微信咨询信息、金融方案、贷款信息、服务费、车辆图片数量、收藏数、浏览数、用户评价、AI 解读、广告内容、非目标车源字段等。

## 字段映射

- 理赔次数 -> 出险次数。
- 最大金额 -> 出险最大金额。
- 漆面 -> 喷漆。
- 换件 -> 更换。
- 同一部位保留最高级别：更换 > 钣金 > 喷漆。

## 样本不足

三同车源少于 3 台时仍正常计算，但结果必须包含“三同车源少于 3 台，样本不足，结论参考性下降，需要人工审核。”。

## 三同车源与参考车

- 三同车源必须同时满足：相同年款内相同配置、相同年份、严格相同颜色。
- 不允许白色/珍珠白、灰色/银灰、金色/香槟金等自动归并。
- 如果 APP 颜色表达与目标车颜色不完全一致，进入人工确认或知识库候选规则，不允许系统自行扩大范围。
- 如果 APP 筛选控件不能精确设置年份，只允许采用“最窄筛选 + 列表二次校验”；过滤后不满足相同年份的车源不能进入三同池。
- 参考车必须来自三同车源池，且价格有效。
- 优先选择评分最接近目标车且价格有效的车源；如果所有三同车源得分都低于目标车，可采用最接近目标车的低分参考车作为临时参考车，但必须标记人工审核。
- 参考车缺少出险次数时按 4 分计算；缺少最大出险金额时按 3 分计算；结果必须提示“目标车或参考车事故字段缺失，需要人工审核”。
- 参考车其他关键字段缺失时，按字段契约进入人工审核或跳过该车，不允许静默计算。
