# 系统总纲

## 目标

“瓜子二手车 APP 数据获取系统”通过手机端自动化操作瓜子二手车 APP，按照页面状态机进入目标页面，采集目标车、参考车、三同车源字段契约内的数据，并输出结构化结果、审计日志和问题记录。

## 总体链路

1. 启动或恢复 APP。
2. 处理 S00 启动广告页：左下角存在跳过按钮时点击；否则等待进入首页。
3. 识别 S01 首页底部导航：首页、选车、卖车、我的。
4. 按 S01 至 S10 的页面状态机完成品牌、车系、车型配置、颜色和车龄筛选。
5. 三同车源结果列表只有 1 台车时，不排序，直接进入详情页；多于 1 台车时，先点 `综合排序`，再选择 `价格从低到高`。
6. 数量未判清时必须报 `COUNT_UNCERTAIN` 停止；只有详情页契约再次确认后，才能进入后续允许的字段采集步骤。
7. 若页面仍同时包含发现页/专区入口与结果列表结构，则该页属于 `S07_DISCOVERY_RESULT_MIXED_PAGE`；此时是否认定为三同车源列表只看来源门禁与强证据：来源若能强证据证明为 `from_s08_view_result` 或 `from_vehicle_detail_back`，则仍可进入三同链路；来源不可靠或证据不足时，报 `RESULT_LIST_SOURCE_UNRELIABLE` 停止。`RESULT_PAGE_VARIANT_UNCLASSIFIED` 仅用于混合页只读诊断后仍无法安全收口来源/路径证据的场景。
8. 计算目标车和参考车得分，第一台参考车得分大于等于目标车得分时停止继续采集。
9. 按定价公式输出结构化结果，必要时标记人工审核原因。
10. 回写飞书字段时，任务编号只读，参考车序号由系统生成。

## 设计原则

- 页面契约优先：未识别页面不点击业务按钮。
- 字段白名单采集：只采集字段契约要求的数据。
- 返回可追溯：只有状态机明确允许返回时才返回，返回后必须校验。
- 异常可学习：未知页面、未知动作、字段缺失、点击异常、返回异常都写入问题记录。
- 工具可降级：优先 adb 与 UIAutomator，缺失时降级到截图和文本识别；仍不可用则完成本地模拟测试并记录原因。

## 已确认业务口径

- 业务目标 APP 是手机上显示名称严格等于“瓜子二手车”的 APP。系统不得因为包名包含 `guazi`、`ganji`、`haoche` 自动确认。
- 只允许打开应用显示名称为“瓜子二手车”的 APP；`com.guazi.android.chesupai` 作为车速拍相关包名必须强制排除。
- 如果无法自动证明唯一一个 launcher APP 的 `app_label` 严格等于“瓜子二手车”，必须停止并报错，禁止启动任何 APP。
- 正式流程不允许通过“人工手动打开 APP 后反推前台包名”确认目标 APP；该方式只能作为调试手段，不进入正式自动流程。
- 启动前允许自动唤醒设备和关闭非安全锁屏；若仍处于安全锁屏或锁屏状态，停止并等待人工解锁，不尝试破解或绕过。
- 正式目标车输入来源为飞书任务，本地 JSON 仅用于模拟测试和离线回归测试。
- 飞书“任务编号”只读，不允许人工填入；“参考车的序号”由系统按采集顺序生成。
- 首页识别必须以 4 个底部导航为准：首页、选车、卖车、我的；“新能源”只作辅助特征。
- “选车”和“买车入口”统一为 S02 选车页，不再使用混合命名。
- 上牌日期必须保存年月原始值；三同车源“相同年份”通过派生年份判断。
- 颜色必须严格相同，不允许白色/珍珠白、灰色/银灰、金色/香槟金等自动归并。
- APP 年份筛选不能精确时，只允许“最窄筛选 + 列表二次校验”；不满足相同年份的车源不能进入三同池。
- 三同车源少于 3 台不中断，但必须提示“三同车源少于 3 台，样本不足，结论参考性下降，需要人工审核。”
- 参考车必须来自三同车源池，且价格有效；允许选择最接近目标车的低分临时参考车，但必须标记人工审核。
- 其他弹窗在没有页面契约前禁止自动点击，只能记录异常、截图/XML、查知识库，未命中则人工介入。
- 当前真机阻塞为 ADB `unauthorized` 时，只等待手机端确认 USB 调试 RSA 授权；授权前禁止继续 APP 点击流程。

## 启动边界

只有当 `app_label == "瓜子二手车"` 且唯一匹配时，才允许执行 `adb shell am start -n 已验证 launch_activity`。启动后只允许获取首屏截图、UIAutomator XML，并判断页面状态是广告页、首页、弹窗或未知页；随后停止等待确认。禁止点击首页、选车、品牌、车源列表或任何车源数据。

## 运行模式

- `simulate`：本地模拟完整链路，用于验证字段契约、评分、输出和异常沉淀。
- `device`：通过 adb 连接真实手机，执行设备检查、包名发现、启动 APP、截图、页面识别和受控动作。

## 输出产物

- `logs/audit.jsonl`：关键动作审计日志。
- `logs/issues.jsonl`：异常与人工介入问题记录。
- `output/result.json`：结构化采集和定价结果。
- `output/execution_feedback_report.md`：执行反馈报告。
- `artifacts/screenshots`：必要截图，禁止保存无关页面证据。

## Runtime Recovery Entry

After `TASK_IMPORT_VERIFIED`, the controller may recover from black screen, Launcher, SystemUI, Home, My tab, `S02`, or `S03`, but it must never bypass secure lockscreen, never click on NotificationShade / third-party overlays, and never open any app other than the verified `?????` target app.
