# Codex 开发规范

## 行为边界

- 不修改原始资料文件夹中的任何资料。
- 不绕过 APP 安全机制，不破解、不反编译、不抓包绕过接口。
- 不采集字段契约外的数据。
- 不在页面契约未命中时执行任何业务点击。

## 代码规范

- Python 代码优先使用标准库。
- 配置集中放在 `config` 目录。
- 运行产物集中放在 `logs`、`output`、`artifacts` 目录。
- 所有关键动作通过 `AuditLogger` 写入 JSONL。
- 所有异常通过 `IssueRecorder` 写入 JSONL。
- 单元测试使用 `unittest`，不依赖外部测试框架。

## 修改流程

1. 先阅读配置和相关测试。
2. 修改代码后运行 `scripts/run_tests.ps1`。
3. 涉及手机链路时运行 `scripts/check_phone.ps1` 和 `scripts/start_app.ps1`。
4. 测试失败先修复，再更新反馈报告。

## 安全默认

遇到不明确的页面、动作或字段时，默认停止业务动作并标记人工介入。若只是目标车选填字段缺失，则按打分规则默认分处理，并写入人工审核原因。

## 已确认边界

- 不新增未确认功能。
- 不扩大采集字段。
- 不改变既有定价公式。
- 目标 APP 必须通过 `app_label == "瓜子二手车"` 且唯一匹配自动证明；禁止包名关键词猜测。
- `com.guazi.android.chesupai` 必须强制排除。
- 无法读取 app label 时必须停止，不允许用 package name 替代。
- 正式流程不允许依赖人工手动打开 APP 后反推包名。
- ADB 状态为 `unauthorized` 时只等待手机端授权，不继续 APP 流程。
- 未建契约弹窗不自动点击。
- 知识库候选方案未 `approved=true` 前不能自动调用。
