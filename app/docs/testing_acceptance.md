# 测试与验收标准

## 本地测试

本地测试必须覆盖：

- 字段契约测试：必填字段、禁止字段、缺失出险字段默认分。
- 页面状态机测试：状态加载、S03 强识别、排序强约束、返回规则。
- 动作执行测试：只允许执行状态内允许动作，禁止动作被拒绝。
- 异常处理测试：问题记录可追溯，返回异常要求重启。
- 输出格式测试：`result.json` 包含目标车、参考车、定价、异常和人工审核原因。
- 手机连接测试：adb 缺失、设备缺失、设备正常三类结果可表达。
- APP 启动测试：包名发现、启动命令、截图失败路径可记录。
- 包名确认测试：首次命中候选包名时必须输出包名、应用名、启动 Activity；人工确认前禁止点击流程。
- APP 身份确认测试：包名包含 `guazi` 但 `app_label` 不是“瓜子二手车”时不得启动。
- 车速拍排除测试：`com.guazi.android.chesupai` 永远不得启动。
- Label 读取失败测试：`app_label` 为空时不得用 `package_name` 替代。
- 唯一匹配测试：只有 `app_label == "瓜子二手车"` 且唯一匹配时才允许启动。
- 唤醒测试：设备黑屏时启动前先执行 `KEYCODE_WAKEUP` 和 `wm dismiss-keyguard`。
- 安全锁屏测试：仍处于锁屏状态时不得绕过，必须停止并等待人工解锁。
- 启动后边界测试：启动后只允许截图和 UI XML 识别，不允许点击页面。
- 首页识别测试：首页、选车、卖车、我的为必需条件；新能源不是必需条件。
- 严格颜色测试：不同颜色表达不能自动归并。
- 年份二次过滤测试：最窄筛选后必须用列表年份字段过滤三同车源。
- 弹窗策略测试：非广告弹窗无页面契约时不得自动点击。
- 知识库测试：只有 `approved=true` 方案可自动调用，最多恢复 1 次。
- ADB unauthorized 测试：设备状态为 unauthorized 时不得执行包名搜索后的点击流程。

## 手机实测验收

至少执行一次：

1. 检查 `adb devices`。
2. 获取设备信息。
3. 搜索或确认瓜子 APP 包名。
4. 尝试启动目标 APP。
5. 截图。
6. 判断广告页或首页。
7. 将结果写入反馈报告。

若 adb 或手机不可用，不阻塞本地工程完成，但最终反馈必须明确失败原因。

如果 ADB 已识别设备但状态为 `unauthorized`，验收只能停在设备授权阶段：等待手机端确认 USB 调试 RSA 授权，授权后重跑 `scripts/check_phone.ps1`；设备状态为 `device` 后再重跑 `scripts/start_app.ps1`。

## 通过标准

- 本地测试全部通过。
- `simulate` 模式能产生结构化结果。
- `device` 模式在失败时能给出结构化失败原因，不乱点页面。
- 输出结果包含样本不足、字段缺失、异常等必要人工审核提示。
